# Soutenance FMFP

Interactive presentation and demo for the FMFP defense, published from this repository’s `main` branch with GitHub Pages.

## Source materials

- Editable 32-page deck and presenter notes: [Canva — Soutenance_Master_editable.pptx](https://www.canva.com/design/DAHYYw1RbIk/yMAed5jEKH4G_CemqY2B_Q/edit).
- Academic source and verified results: [Mémoire BIHAR - Jaona](https://docs.google.com/document/d/1HkJqncqdpr5-YXKSU1pKSvgwRUOvOYB2Tw_RNfQCxCc/edit).
- The local 32-slide presentation and narration are in [`index.html`](index.html), including six section dividers matching Canva’s page order. The demo walkthrough is stored in the same file; images are in `img/`.
- Supporting evidence and validation notes are kept outside this repository in `../fmfp/stage_doc/` and are not published with the site.

The Canva deck and this interactive site are separate sources; they do not sync automatically. When updating a claim, metric, or speaker script, reconcile the thesis, Canva slide and notes, and matching local slide and narration before publishing. Keep deployment and rollback claims aligned with the latest validation evidence.

## View and install

Open the site at <https://jaonaaa.github.io/soutenance-fmfp/>. On iPhone, use Safari’s Share menu and **Add to Home Screen**. On Android, use the browser’s **Install app** action. The service worker stores the slides and demo images for offline use; update its cache name when changing these files.
