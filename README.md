# Soutenance FMFP

Static presentation deck and speech notes for the FMFP defense, published from the `main` branch root with GitHub Pages.

The published site contains the presentation, its used images, the app icons, and the offline service worker. Working notes in `stage_doc/` stay local and are excluded from Git.

Open the site at https://jaonaaa.github.io/soutenance-fmfp/. On iPhone, use Safari’s Share menu and **Add to Home Screen**. On Android, use the browser’s **Install app** action. The service worker stores the slides and demo images for offline use; update its cache name when changing these files.
